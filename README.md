A bedtime story that turns on its second sentence — the narrator reads to two children, but only one of them is really there.

## Entry

> I tucked both my children into bed at nine and read them the same story I read every night. When I finished, the one on the left asked me to read it again, and the one on the right asked who I was talking to.

## How it works

`main.py` (Python 3 standard library only) writes the entry text above to `entry.txt` in the output directory given by the `MAKEFUN_OUTPUT_DIR` environment variable, falling back to `/output`. The file contains exactly the two-sentence entry — 208 characters, 208 bytes, no trailing newline.
